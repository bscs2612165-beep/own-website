ROADMAP & RESOURCES
What to Learn & How
💻
C Language — Start Here
Your Fundamentals of Programming course at uni uses programming concepts. C language will make it 10x easier. Learn variables, loops, functions, arrays — then try small programs daily.
RESOURCES:
→ CS50 Harvard (free, best beginner course) → learn-c.org (interactive practice) → CodeWithHarry YouTube (Urdu/Hindi)
🗄️
SQL — Complete Beginner Path
SQL lets you talk to databases. Start with SELECT, WHERE, JOIN. You'll use this in almost every CS job. It's very learnable — give it 2–3 weeks of daily practice and you'll be solid.
RESOURCES:
→ SQLBolt (interactive, free) → W3Schools SQL (quick reference) → freeCodeCamp SQL Full Course (YouTube)
🤖
AI Tools & Websites
Learn by using them. Try ChatGPT, Claude, Gemini for study help. Then explore Midjourney/DALL-E for images, Suno for music, ElevenLabs for voice. Understanding AI tools is a huge career skill in 2026.
TOOLS TO TRY:
→ Claude.ai (AI assistant — you're using it!) → Suno.com (AI music generation) → ElevenLabs (AI voice generation) → HuggingFace Spaces (explore AI demos)
🎬
CapCut & Video Editing
CapCut is great for content creation. Learn cuts, transitions, subtitles, trending effects. This is a creative skill that can earn you money as a freelancer while you're still in uni.
HOW TO LEARN:
→ CapCut Beginner Tutorials (YouTube) → CapCut Web Version (practice online)
💡 Tip: Edit 1 short video per week. Post on Instagram Reels to track your progress.
